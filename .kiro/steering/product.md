# Product

This repository is an **Obsidian knowledge vault** that serves as the single source of truth for the BorondoTours project. It is not a code repository — it is a documentation and planning hub.

## Purpose
- Store and manage project specs, ADRs, and knowledge
- Bridge between design tools (Claude Desktop / Obsidian) and the coding environment (Kiro IDE)
- Provide structured context to AI assistants working on the codebase

## Connected tools
- **Kiro IDE** — reads specs and steering files to guide code generation
- **Claude Desktop** — reads/writes vault notes via MCP (mcp-obsidian)
- **Obsidian** — primary UI for browsing and editing the vault

## Language
- Documentation and notes: **Spanish**
- Code and code comments: **English**
- AI responses should be in **Spanish**
